pi-worklist: `project next`, `project ready`, `project waves`
============================================================

End-to-end CLI transcript. Every `$ pi-worklist ...` line below was really run
against `node src/cli.ts` in a throwaway git repo, and the text underneath it is
that command's real stdout followed by its real exit code.

`branch` is stamped by hand where a scenario needs it, because no CLI action
writes that field yet - the separate project-start goal will. Cycles and edges
naming a missing goal are likewise hand-written, since mutations refuse them.

==============================================================

==============================================================
 10. The three reads are discoverable in the CLI's own usage
==============================================================

$ pi-worklist project help
Actions:
  list                                     Show a compact bounded list of project goals
  show <id>                                Show one goal with its full description
  find <text...>                           List the goals whose title or description contains the text
  next                                     Show the one goal to start next, the first ready goal in file order
  ready                                    List every unblocked, unclaimed open goal: the whole parallel frontier
  waves                                    Print unfinished goals in dependency layers, earliest first
  ui                                       Open the interactive goal board for a human at the keyboard
